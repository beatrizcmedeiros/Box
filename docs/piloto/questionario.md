# Questionário de feedback do piloto

Curto (menos de 3 minutos). Pode ser aplicado no Google Forms ou em papel. Anônimo para os alunos.

## Alunos

1. Você instalou o PR Box na tela inicial do celular? (Sim / Não / Não consegui)
2. Em quantos treinos por porcentagem você usou o app nestas duas semanas? (0 / 1 / 2–3 / 4 ou mais)
3. De 1 a 5, quão fácil foi encontrar a carga do treino no app? (1 = muito difícil, 5 = muito fácil)
4. De 1 a 5, quanto o app ajudou a não precisar calcular a carga? (1 = nada, 5 = muito)
5. Alguma vez a carga mostrada pareceu errada? (Não / Sim — qual exercício?)
6. Você conseguiu ver suas cargas sem internet no box? (Sim / Não / Não precisei)
7. O que mais atrapalhou ou faltou? (aberta)
8. Você recomendaria o PR Box para os colegas de outras turmas? (0 a 10)

## Treinador

1. De 1 a 5, quão fácil foi cadastrar os alunos e repassar as senhas?
2. Quanto tempo levou para importar a lista do teste de força? Precisou corrigir muitas linhas?
3. A consulta de cargas com filtros foi útil? Para quê você usou?
4. Percebeu diferença no ritmo da aula nos treinos por porcentagem? (Mais rápido / Igual / Mais lento)
5. O que precisa mudar antes de liberar para todas as turmas? (aberta)
6. Posso usar suas respostas como depoimento no relatório do projeto de extensão? (Sim / Não) — se sim, nome e cargo.
